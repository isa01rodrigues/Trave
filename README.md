# 💻 Traver | Plataforma de Locação de Equipamentos de TI

> **Projeto Full Stack desenvolvido para uma empresa de locação de equipamentos de tecnologia, reunindo um website institucional e um sistema web administrativo para gerenciamento completo dos serviços.**

## 📖 Sobre o Projeto

O **Traver** é uma plataforma desenvolvida para atender uma empresa especializada na **locação de equipamentos de tecnologia**, como desktops, notebooks, monitores, periféricos e outros dispositivos corporativos.

O projeto foi dividido em duas frentes complementares:

* 🌐 **Website Institucional:** responsável por apresentar a empresa, seus serviços e equipamentos disponíveis para locação.
* 🖥️ **Sistema Web Administrativo:** desenvolvido para gerenciar as informações da plataforma, permitindo o cadastro, consulta, atualização e remoção de dados por meio de um **CRUD completo**.

Durante o desenvolvimento, foram aplicados conceitos de **desenvolvimento Full Stack**, integrando uma interface moderna e responsiva com um sistema robusto em PHP para gerenciamento das operações da empresa.

---

## 🎯 Objetivos do Projeto

* Desenvolver um website institucional para divulgação da empresa;
* Criar um sistema administrativo para gerenciamento dos equipamentos;
* Aplicar operações completas de banco de dados (CRUD);
* Desenvolver uma interface intuitiva e responsiva;
* Integrar Front-end e Back-end em uma única solução.

---

## 🗄️ Sistema de Gerenciamento (CRUD)

O sistema administrativo foi desenvolvido utilizando **PHP** para implementar todas as operações fundamentais de gerenciamento de dados.

Foram desenvolvidas as seguintes funcionalidades:

* ➕ **Create** — Cadastro de novos equipamentos;
* 📄 **Read** — Consulta e listagem das informações;
* ✏️ **Update** — Atualização dos registros;
* 🗑️ **Delete** — Remoção de equipamentos do sistema.

Essa estrutura permite administrar os dados da plataforma de forma organizada e eficiente.
